==================================================
2. PROJECT CONCEPT
==================================================

The system is an AI-powered Digital Twin platform for home-based shoulder physiotherapy.

The patient uses a smartphone application to:

1. Register/login
2. View their assigned shoulder exercise plan
3. View exercise instructions/demonstrations
4. Start an exercise session
5. Use the smartphone camera to capture movement
6. Receive exercise-performance feedback
7. See repetition/set counts
8. See a Digital Twin representation of their movement
9. Complete the exercise
10. View session history and performance progress
11. Submit difficulty/discomfort feedback
12. Trigger an Emergency Alert during an active exercise session

The physiotherapist already has a separate web dashboard.

The patient application should eventually communicate with the same backend/data layer so that:

Physiotherapist assigns exercise
        ↓
Patient sees assigned exercise
        ↓
Patient performs exercise
        ↓
Movement/session data is generated
        ↓
Data is stored
        ↓
Physiotherapist can monitor the patient's performance
